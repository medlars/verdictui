- **Probe PLACEMENT decides what gets measured, and getting it wrong fails silently toward PASS.** A probe attached OUTSIDE a `.frame(width:)` measures the frame, so `intrinsicWidth` comes back equal to the constrained width and truncation is invisible; moving it inside catches the same defect.
